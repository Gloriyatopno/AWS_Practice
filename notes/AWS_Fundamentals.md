# 1. AWS Account Setup

## What is AWS?

Amazon Web Services (AWS) is a cloud computing platform that provides services such as compute, storage, databases, networking, security, monitoring, and many others.

AWS allows applications and infrastructure to be created and managed without owning physical servers.

## AWS Account

An AWS account provides access to AWS services and resources.

During account setup, billing information and identity verification may be required.

### Important Account Concepts

- Root user — The original account identity created when the AWS account is created.
- IAM user — An identity created inside an AWS account for accessing AWS resources.
- Account ID — A unique identifier for an AWS account.
- Account alias — A human-readable name used as part of the IAM sign-in URL.

---

# 2. AWS Root User

The root user has complete access to the AWS account.

The root user should only be used for tasks that specifically require root-level access.

### Root User Best Practices

- Enable MFA.
- Do not use the root user for everyday AWS administration.
- Do not create or share root access credentials.
- Protect the root account email and password.
- Use IAM users or roles for regular work.

# 3. Multi-Factor Authentication (MFA)

MFA adds an additional authentication factor when signing in.

Instead of relying only on a password, AWS can require a temporary verification code generated by an authenticator application.

## Root Account MFA Setup

Steps:

1. Sign in to the AWS root account.
2. Open the account/security settings.
3. Select the option to assign MFA.
4. Choose a virtual MFA device/authenticator application.
5. Scan the QR code using an authenticator application.
6. Enter the generated MFA codes.
7. Complete the MFA registration.

### Why MFA is Important

MFA provides additional protection if a password is compromised.

MFA should be enabled for privileged accounts.

# 4. IAM — Identity and Access Management

AWS Identity and Access Management (IAM) controls who can access AWS resources and what actions they are allowed to perform.

IAM can be used to manage:

- Users
- Groups
- Roles
- Policies
- Permissions
- MFA

---

# 5. IAM Users

An IAM user represents a person or application that needs access to AWS resources.

## IAM User Setup

Steps:

1. Open the AWS Management Console.
2. Search for IAM.
3. Open IAM.
4. Select Users.
5. Choose Create user.
6. Enter the username.
7. Enable console access if required.
8. Set the required authentication method.
9. Add the user to an appropriate group.
10. Complete user creation.

### IAM User Created

An administrative IAM user was created for AWS learning and administration.

The user was added to an IAM group with the required permissions.

---

# 6. IAM Groups

An IAM group is a collection of IAM users.

Groups make permission management easier because permissions can be assigned to the group instead of individually configuring every user.

## IAM Group Setup

Steps:

1. Open IAM.
2. Select User groups.
3. Choose Create group.
4. Enter a group name.
5. Select the required policy.
6. Create the group.
7. Add the required IAM users to the group.

---

# 7. IAM Policies

An IAM policy defines permissions.

A policy determines which AWS actions are allowed or denied on which resources.

Policies are commonly written as JSON documents.

Example structure:

```json
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Effect": "Allow",
            "Action": "service:Action",
            "Resource": "*"
        }
    ]
}
