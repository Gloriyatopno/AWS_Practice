# AWS Practice

## Overview

This folder contains my AWS learning notes, service comparisons, and revision materials prepared as part of my internship learning tasks.

## Topics Covered

### 1. AWS Fundamentals and IAM

* AWS Cloud fundamentals
* Global infrastructure
* IAM, users, groups, roles, and policies
* Security and shared responsibility
* AWS CLI and pricing fundamentals

### 2. Compute and Storage

* Amazon EC2
* Amazon EBS and EFS
* Amazon S3
* Containers and serverless computing

### 3. Networking, Scaling, and Application Services

* Amazon VPC and networking
* Elastic Load Balancing
* EC2 Auto Scaling
* AWS Lambda and API Gateway
* Event-driven application services

### 4. Deployment, Databases, Governance, and Security

* AWS deployment and automation tools
* Relational and NoSQL databases
* Analytics services
* Management and governance
* AWS security and identity services

### 5. Architecture, Billing, and Migration

* AWS Well-Architected Framework
* AWS pricing and cost management
* AWS Organizations and support plans
* Migration strategies and services
* Machine learning, end-user computing, and IoT

## Learning Objectives

* Understand core AWS services and their use cases.
* Learn cloud architecture and security best practices.
* Compare AWS services based on application requirements.
* Understand deployment, migration, and cost optimization.
* Build a foundation for practical AWS projects.
